### Projetos Recentes
1. Participação no desenvolvimento da ferramenta de revisão sistemática StArt:
Sistema web voltado à organização de revisões sistemáticas de forma dinâmica e
eficiente. Participei da construção da interface utilizando ReactJS e TypeScript,
garantindo tipagem estática e maior robustez. A aplicação utiliza HTML5, CSS3 e
JavaScript moderno (ES6+), além de integrar dados via API REST com requisições
assíncronas, utilizando Axios e a biblioteca UseSWR para gerenciamento de cache e
revalidação de dados.
[Link do projeto](https://github.com/pet-ads/systematic-front)

2. **Wisely**
API desenvolvida com foco na organização de estudos, permitindo funcionalidades
como criação de resumos, flashcards, envio de arquivos e proteção de dados sensíveis.
A arquitetura do projeto segue os princípios de Domain-Driven Design (DDD), SOLID e
Clean Architecture, com estrutura modular e escalável. A implementação foi feita em
NodeJS com TypeScript, utilizando Express para definição de rotas, Prisma ORM para
acesso ao banco de dados MySQL e JWT com Bcrypt para autenticação e criptografia.
Também foram desenvolvidos testes unitários e de integração utilizando Jest,
garantindo a confiabilidade e a qualidade do sistema.
[Link do projeto](https://github.com/GuilhermeAMendes/wisely-backend)

3. **WECOMP VI**
Responsável pela criação e estruturação de uma landing page institucional para
divulgação da programação e atividades da Semana da Computação. A interface
prioriza a experiência do usuário com um design limpo e responsivo. Desenvolvida
com ReactJS e TypeScript, combinando HTML5, CSS3 e JavaScript ES6+. Os dados são
renderizados de forma estática a partir de estruturas de dados tipadas.
[Link do projeto](https://github.com/pet-ads/wecomp-new)
