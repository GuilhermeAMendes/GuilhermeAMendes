Sou Analista de Desenvolvimento Júnior em P&D, com forte atuação como desenvolvedor Fullstack. - Desenvolvendo aplicações mobile com **React Native** em projetos independentes, como o app **Viva**.
- Estudante de Tecnologia em Análise e Desenvolvimento de Sistemas no IFSP/SCL.
- Experiência prévia com desenvolvimento web no PET ADS e TI na Prominas Brasil.

### Projetos e Experiências Recentes

1. **Projeto Viva (Mobile)**
Desenvolvimento de aplicativo mobile utilizando React Native. O projeto envolve a criação de interfaces dinâmicas e responsivas diretamente focadas na experiência do usuário em dispositivos móveis.

2. **Sage Toolkit**
Refatoração e modularização de um sistema backend legado em serviços de infraestrutura completamente reutilizáveis. O projeto englobou a implementação e padronização de ORM, sistemas robustos de autenticação baseados em tokens (JWT) e módulos de criptografia, melhorando a segurança e escalabilidade.

3. **Wisely**
API desenvolvida com foco na organização de estudos, permitindo funcionalidades como criação de resumos, flashcards, envio de arquivos e proteção de dados sensíveis. A arquitetura segue princípios de Domain-Driven Design (DDD), SOLID e Clean Architecture. Implementada em NodeJS com TypeScript, utilizando Express para rotas, Prisma ORM para MySQL e JWT com Bcrypt.
[Link do projeto](https://github.com/GuilhermeAMendes/wisely-backend)

4. **StArt (Ferramenta de Revisão Sistemática)**
Sistema web voltado à organização de revisões sistemáticas de forma dinâmica e eficiente. Participei da construção da interface utilizando ReactJS e TypeScript, garantindo tipagem estática e maior robustez. A aplicação integra dados via API REST com requisições assíncronas utilizando Axios e UseSWR.
[Link do projeto](https://github.com/pet-ads/systematic-front)

5. **WECOMP VI**
Criação e estruturação de uma landing page institucional para divulgação da programação da Semana da Computação. A interface prioriza a experiência do usuário com design limpo e responsivo. Desenvolvida com ReactJS, TypeScript e renderização estática a partir de estruturas de dados tipadas.
[Link do projeto](https://github.com/pet-ads/wecomp-new)
